# jingjia-stock-selector-custom-skill

个人版 9:25 集合竞价选股 Skill，基于 Tushare 数据运行 A 股超短线竞价筛选与盘后回测。

本仓库是个人可编辑版本，核心策略为 `v5-Top3`：使用 `stk_auction` 统一实时筛选和历史回测数据源，按竞价量能、开盘位置、连板位置、板块热度、竞价形态和风控项综合评分，最多输出 TOP3 候选标的。

## 适用场景

当用户明确表达以下意图时使用本 skill：

- 跑我的竞价策略、我的短线策略、我的选股
- 使用个人版、自定义版、custom 竞价策略
- 调整评分权重、风控阈值、筛选条件
- 对个人竞价策略做历史回测或复盘

通用的「竞价选股」「今天买什么」「打板」类请求，应优先由通用版 `jingjia-stock-picking` 处理。

## 功能

- 每日 9:25 竞价筛选：读取当日集合竞价数据和昨日涨停数据，输出候选池、情绪判断和 TOP3。
- 盘后回测：按指定区间复盘策略表现，统计胜率、均收、累计收益和分数段表现。
- 策略参数可编辑：可直接修改评分权重、硬排除条件、退潮判断、TOP 数量等。
- Tushare Token 自动读取：优先读取环境变量 `TUSHARE_TOKEN`，也兼容 `~/.openclaw/openclaw.json` 中的配置。

## 环境要求

- Python 3.7+
- Tushare Pro 可用账号和 Token
- 网络访问权限

安装依赖：

```bash
pip install tushare pandas
```

配置 Token：

```bash
export TUSHARE_TOKEN="你的 tushare token"
```

## 使用方法

每日选股：

```bash
python scripts/run_daily.py --date 20260508
```

不指定日期时，脚本会尝试使用最近交易日：

```bash
python scripts/run_daily.py
```

区间回测：

```bash
python scripts/run_backtest.py --start 20260409 --end 20260508
```

快速回测：

```bash
python scripts/run_backtest.py --quick
```

## 输出说明

每日选股脚本会输出：

- 市场情绪：根据昨日最高板、3进4晋级率等指标判断是否适合接力。
- 首选买入池或观察池：退潮期只输出观察，不推荐接力。
- 候选标的表格：包含股票、代码、连板、竞开涨幅、竞价额占流通市值比、评分。
- 最终结论：给出是否可操作以及首选标的。

回测脚本会输出：

- 总交易笔数、胜率、平均收益、累计收益
- 每日表现
- 不同分数段表现
- TOP3 明细
- 与历史版本的简要对比

## 核心策略摘要

评分由五类因子组成：

- 竞价量能：竞价额占流通市值比例。
- 开盘位置：竞价开盘涨幅所在区间。
- 连板位置：首板、2板、3板、4板以上分别计分。
- 板块热度：概念或题材热度加权。
- 竞价形态：昨日板质量与今日竞价承接组合。

主要风控规则：

- 退潮期不输出买入池。
- 排除 ST、北交所、市值过小、大幅低开、竞价无量、封单质量过弱等标的。
- 单日最多输出 TOP3。
- 禁止把筛选结果表述为确定性收益或无风险机会。

完整执行细节以 `SKILL.md` 和脚本实现为准。

## 调参入口

常见可调整位置：

- `SKILL.md`：触发词、策略说明、评分规则、输出格式和风控原则。
- `scripts/run_daily.py`：每日筛选逻辑、硬排除条件、评分阈值、情绪判断。
- `scripts/run_backtest.py`：回测区间、买卖规则、评分逻辑、绩效统计。

调参后建议先运行回测，再用于实时筛选。
